# 防災Sowing 会員アプリ（初期画面）

## 含まれるファイル
- `index.html`：画面構成
- `style.css`：デザイン
- `app.js`：画面切り替え
- `logo.jpeg`：共有いただいた公式ロゴ
- `supabase.sql`：共有データベース用のテーブル案

## 重要
この版は画面の土台です。まだイベント・参加者・お知らせは端末間で共有されません。
氏名を扱うため、公開状態で誰でも読み書きできる設定にはしていません。
次の工程でSupabase等のデータベースと会員認証・管理者権限を安全に接続します。

## GitHubへの配置
ZIPを解凍し、5ファイルをリポジトリのルートにアップロードしてください。
`index.html` はルート直下に置きます。`index 4.html` のような別名では公開ページとして使われません。
